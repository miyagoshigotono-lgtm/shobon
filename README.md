# ねこのアクション

理不尽トラップだらけの鬼畜横スクロールアクションゲーム。全5ステージ。

## 遊び方

- **スマホ**: 左下の ◀▶ で移動、右下の ▲ でジャンプ!
- **PC**: 矢印キー or WASD + スペースorZ でジャンプ
- **やりすぎ防止**: 遊べるのは1回 20分まで。残り時間は画面上部に表示され、20分たつと強制きゅうけいのメッセージが出る

## ステージ構成

| STAGE | 内容 |
| --- | --- |
| 1 | 理不尽トラップ入門 |
| 2 | 極悪リニューアル面 (孔明の罠・大砲・迫る壁) |
| 3 | 「じゅうりょく、はんてん。」— ジャンプが重力反転になる回廊と、勝手に進む土管の空 |
| 4 | 「たましいの いろ」— ？ブロック、ドッスン、そして枠の中でホネを避ける弾幕戦闘 (あおは うごくな！) |
| 5 | 「このゲームは あなたを しっている」— 進むべき方向も、床も、エンディングすらも信用できないメタ地獄 |

STAGE 3 以降は死んで覚える鬼畜難易度。どこかで遊んだことのあるゲームの記憶が試される。

## GitHub Pages への公開手順

1. このリポジトリを GitHub に push する
2. Settings → Pages → Branch: `main` / `/(root)` を選択して Save
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能

## スマホでホーム画面に追加（PWA）

Safariでアクセス → 共有ボタン →「ホーム画面に追加」  
Chromeでアクセス → アドレスバーのインストールボタン
